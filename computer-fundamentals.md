# Computer Fundamentals --- Learning Notes

**Status:** Beginner study notes\
**Purpose:** Build a foundation for future cybersecurity and SOC Analyst
learning.

## 1. CPU (Central Processing Unit)

The CPU executes instructions and processes data. It is often described
as the computer's main processor.

**Why it matters for cybersecurity:** Understanding normal system
activity helps when learning how processes run and how unusual behavior
may be investigated.

## 2. RAM (Random Access Memory)

RAM temporarily stores data and programs currently being used. Its
contents are generally cleared when the computer powers off.

**Remember:** RAM is working memory, not long-term file storage.

## 3. SSD and HDD

SSD and HDD devices store files, applications, and operating-system data
over the long term.

-   **SSD:** Uses flash memory and is generally faster.
-   **HDD:** Uses spinning magnetic disks and is often cheaper per unit
    of storage.

## 4. Hardware and Software

-   **Hardware:** Physical components, such as the keyboard,
    motherboard, RAM, and storage drive.
-   **Software:** Programs and instructions, such as a browser, text
    editor, or operating system.

## 5. Operating System (OS)

An operating system manages hardware resources and provides services
that applications use. Examples include Windows, Linux, and macOS.

## 6. Windows Task Manager --- Safe Practice

1.  Press `Ctrl + Shift + Esc` to open Task Manager.
2.  Review the **Processes** tab.
3.  Observe CPU, memory, disk, and network usage.
4.  Open the **Performance** tab and identify CPU and memory
    information.
5.  Do not end unfamiliar processes just for experimentation.

## Key takeaways

-   The CPU processes instructions.
-   RAM temporarily holds active data.
-   SSDs and HDDs provide long-term storage.
-   Hardware is physical; software is made of programs and instructions.
-   The OS manages the computer's resources and supports applications.
