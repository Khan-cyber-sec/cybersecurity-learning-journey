# Cybersecurity Learning Journey

A beginner-friendly portfolio documenting my progress from computer
fundamentals toward cybersecurity and SOC analysis.

## Learning goals

-   Understand computer hardware and software fundamentals
-   Build networking fundamentals
-   Learn Windows and Linux basics
-   Study cybersecurity concepts and common threats
-   Practice SOC concepts such as logs, alert triage, and incident
    response

## Topics covered

### 1. Computer Fundamentals

-   CPU: executes instructions and processes data
-   RAM: temporarily holds data and programs in use
-   SSD/HDD: stores files, applications, and the operating system
    long-term
-   Hardware vs. software
-   Operating system basics
-   Windows Task Manager: observing processes and resource usage

See [Computer Fundamentals Notes](notes/computer-fundamentals.md).

## How I use this repository

I add concise notes, safe practice exercises, and key takeaways as I
learn. The goal is to document genuine progress and build a useful
reference for future study.
